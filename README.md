# Pomodoro Web

기존 Pomodoro 안드로이드 앱을 React와 TypeScript로 옮긴 웹 버전입니다. 타이머 화면 모드 3종, 할 일, 기록, 통계, 집중 화면과 수집품 전시관을 제공합니다. 안드로이드 앱의 타이머 삽화와 수집품 WebP 12종을 그대로 사용합니다.

## 실행

Node.js 22.12 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

Vite가 표시하는 주소에서 앱을 엽니다. `npm run build`는 타입 검사 후 배포용 정적 파일을 `dist/`에 생성합니다. `npm run preview`로 빌드 결과를 확인할 수 있습니다.

## 저장과 알림

- 설정, 세션, 할 일, 기록, 수집품은 브라우저의 IndexedDB에 저장됩니다. 같은 브라우저에서 같은 주소로 연 탭은 데이터를 공유합니다.
- 타이머가 실행 중일 때 탭을 닫거나 새로고침해도 마감 시각을 기준으로 복구합니다. 자동 시작은 타이머가 화면에 보이는 상태에서 완료가 처리될 때 동작합니다.
- 완료 소리와 진동은 페이지가 보이고 브라우저가 허용하는 경우 동작합니다. 시스템 알림, 백그라운드 푸시, 탭 종료 후 알람은 웹 버전 범위에서 제외했습니다.
